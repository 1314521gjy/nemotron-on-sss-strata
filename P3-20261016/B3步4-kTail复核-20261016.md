## §3 发现的"写死"（3 处，2 类）

### (a) `moe_card:2078` —— **与本路径相关，但是有意守卫**
```cpp
if (!L.gated) return false;   // the card's routed launches are wired for gated experts (moe_rows() takes it next)
```
- **它确实是"非门控走不通"的一处**，但：**① 有注释说明"moe_rows() takes it next"（后续计划）；② 返回 false ⇒ 上层回退（`:2622 if (!moe_card(...)) return false;`），不是算错。**
- ⇒ **性质 = 已知的、注明的"未接线"，不是静默写死**。**影响面 = 那条 GPU 路由发射路径的性能/回退**，**不涉正确性**。
- ⇒ **处置建议**：**保持现状 + 保留注释**；若将来接线，**它才是"需要构造"的地方之一**（与 §3(b)(c) 不同类）。

### (b) ★ **裸 `256` 三处 —— `kTail` 的第二份字面量定义**
| 行 | 代码 | 问题 |
|---|---|---|
| `:1048` | `vmm_map(arena_, arena + 256, …)` | 裸 256 |
| `:1057` | `dmalloc(arena + 256, …)` | 裸 256 |
| `:1059` | `cudaMemset(exp_, 0, arena + 256)`，**注释自称 "the slots' tails stay zero (kTail)"** | ★ **注释承认它就是 kTail，却写死** |
- 对照：**同一件事在 `stage()` 里写的是 `kTail`**（`:2133` `cudaMemsetAsync(stage_ + down_at + m*L.d_bytes, 0, kTail, …)`）⇒ **同义两写法**。

- ⇒ **建议**：把这三处改成 `kTail`（**一行级**）；这是**消除"同一个常量两份定义"**，属卫生，非紧急。
