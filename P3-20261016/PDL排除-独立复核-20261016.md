# PDL「本线不存在」双重排除 —— 独立复核（只读）— verifier

> 任务：独立复核 scheduler 的结论（**不照抄**）。特别核 **build 的 arch 到底是不是纯 sm_89**（有无 `compute_90` 多目标 PTX）。
> **只读**：未跑 GPU、未编译、未改码。**AI：deepseek-flash[1m]** ⇒ **自验，不构成独立验收**。证据 **A** = 本机读源码 / 读二进制。

## 判定：**成立**（双重排除都成立）—— 且我补了一条**二进制级**证据

### 排除 ①：`pdl_scope()` 默认 false，只由 RAII 置位 —— **成立**（A）
- `verify_kernels.cu:1443-1445`：`bool& pdl_scope() { static thread_local bool on = false; return on; }` ⇒ **默认 false、且 thread_local**。
- **写点穷举**（`grep pdl_scope()` 全树）只有两处：
  - `verify.cpp:899-900` = `PdlScope` RAII（`explicit PdlScope(bool on) : prev(pdl_scope()) { pdl_scope() = on; }`），其构造实参是 `G == 1 && pdl_supported()`（`:901`）⇒ **仅录图那条窗口开**；
  - `pdl_parity.cpp:128/133` = **测试/对标工具**（非引擎路径）。
  ⇒ **引擎生产路径上，唯一置位者就是那个 RAII 窗口**。

### 排除 ②：asm 只在 `__CUDA_ARCH__ >= 900` 编译 + 本线 sm_89 —— **成立**（A，且我加验了二进制）
- `include/strata/kernels/pdl.hpp:63` / `:69`：`#if !defined(__HIPCC__) && defined(__CUDA_ARCH__) && (__CUDA_ARCH__ >= 900)` ⇒ **asm 只在 ≥900 的目标里被编译**。
- **★ 你要我查的构建参数（我查了，不是转述）**：
  - `build-p3/CMakeCache.txt:64` ⇒ **`CMAKE_CUDA_ARCHITECTURES:UNINITIALIZED=89`**；
  - `CMakeLists.txt:166-167` 的 `120` **只在"未定义时"才设**（`if(NOT DEFINED …)`）⇒ **被 cache 的 89 覆盖**；
  - `CMakeLists.txt:1455` 的 per-target 也取自**同一个变量** ⇒ **仍 89**。
  ⇒ **唯一的 gencode 目标 = compute_89 / sm_89** ⇒ `__CUDA_ARCH__ == 890 < 900` ⇒ **asm 不编译**。
  - ★ 关键区分：**CMake 为 `89` 会同时生成 `code=sm_89` 与 `code=compute_89`(PTX)** —— 但那**仍是 89**，**`890 < 900` 照样不编译**。**要破坏②，必须存在 compute_90+ 目标，而配置里没有。**
- **★ 我补的二进制级证据（A，最直接）**：
  - `grep -a -o "compute_[0-9][0-9]" build-p3/strata-poly.exe` ⇒ **零命中**；`sm_[0-9][0-9]` ⇒ **只有 `sm_89`（26 处）**。
  - `grep -a -c "griddepcontrol" build-p3/strata-poly.exe` ⇒ **0**。
    ⇒ **若嵌了含 PDL 的 PTX，`griddepcontrol` 会以明文出现；它零命中 ⇒ 二进制里根本没有 PDL asm**。
  ⇒ **② 不仅有"配置级"依据，还有"二进制级"实证。**

## 结论
**PDL 在本线不存在 —— 双重排除均成立**；且**第②重排除经二进制核验**（只有 sm_89、没有 `griddepcontrol`），**不是仅靠 sm_89 这一句推断**。
⇒ **scheduler 的"杀候选"结论可采信**（就本条而言）。
