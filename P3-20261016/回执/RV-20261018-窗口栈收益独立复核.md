## 关键决定 / 对 lead 判据的答复

1. **"窗口栈=最大杠杆"目前只有 p6792 模板证据**（+57%/+77%）；alt 上 −2.8%（lookup）/ +2.2%（draft，且驻留混杂）⇒ **不能称最大杠杆**；判决实验须在 ≥2 条异构 prompt 上过 15% 才有资格。
2. **拆分口径**：乘法而非加法——`倍速 = tokens/round ÷ 轮成本比`；p6792 的 8 token/轮来自 100% 接受（模板），8 token 的轮只花 5.05/4.45 单 token 成本（窗口栈批处理）⇒ 这是唯一可拆出的两块；"lookup 跳过计算"无可观测份额。
3. **建议补的 3 条**（已写进 §5）：a) 同批 CTRL 首尾配对 + 预热剔除；b) 三列同报（tokens/round 标推算 + accepted/offered + per-round ms 拆 CPU 腿/非CPU）+ ≥2 异构 prompt；c) 质量+自证捆绑（exe sha、窗口自证、ids 逐位≥2 prompt、全位置 Δp、copy-ledger 两列、R21 峰值）。
4. **口径纠偏**：跑法脚本 239/224/168（非 235/228/170）；交接件 §53 的"D2 203 ms/轮"与日志复算 177.5 ms/轮差 12.6%，需统一（当前不能作结论）。
