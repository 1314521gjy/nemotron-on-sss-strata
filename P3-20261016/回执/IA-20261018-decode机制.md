## 3. 结论（一句话）
**`wait for rings` 等的是 GPU 自己**（图内 `doorbell_publish` 在每层 pre 半段结束时写 mapped-pinned seq；host 只自旋读 → 12.378 ms = 48 层 GPU pre 时间）；**`pool` 是 host 在算 CPU 专家**（151 µs/层、133 µs/漏专家），但它**卡住 GPU**（图内 post 等 pool 的 flag）⇒ 每层"GPU pre→CPU pool→GPU post"握手串行；账闭合 = 12.378+7.269+0.101+0.037+**MTP 2.360**+尾/杂≈2.17 = **24.31 ms/轮**，÷2.63 token/轮 = **9.24 ms/token**。⇒ **机制压每层常数、几何压上限：都要抄，但先抄"GPU 路由+门铃"（机制，可拿 6.6 ms/token 的 host 往返），再抄"驻留/tail-skip/pcie"（几何，拿 CPU 池×4），最后整图+MTP。**
