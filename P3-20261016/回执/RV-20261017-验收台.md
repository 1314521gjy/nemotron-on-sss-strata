## 关键决定

1. **基线选 `pair_D_pb6912.log`**：它是唯一 pb=6912 + tile=1 的跑，且 652.6/12.30 与交接件 §0/§1.3 一致、exe sha 可绑（`run_pb6912_D.cmd:12` + `sp_tile.exe` sha cc2a9851 + mtime 序）。**没有改基线去迁就任何东西**。
2. **确定性项做硬门、tok/s 项做噪声门**：ids / 驻留槽 / DMA 次数 / EXIT 是确定性计数器（可直接红）；prefill/decode 有跑间噪声（p56 同配置：prefill 极差 0.31%，decode 单跑上界 −8.6%~+4.1%），所以 tok/s 判硬绿/硬红要求 **3 跑中位**，n=1 只给"暂绿/待复现"。
3. **脚本 ASCII-only、不用临时文件**：直接 `[IO.File]::ReadAllLines` / `[regex]`，中文路径（含 `负控\`）已实测可跑；`-LiteralPath` 语义由 .NET API 天然满足。本机是 **PowerShell 5.1**（实测 `$PSVersionTable`），脚本按 5.1 语法写并已做过 parser 检查。
4. **probs 不造假**：pair_D 无 `--top-probs`，全实验区搜不到该 prompt 的 `top` 行 ⇒ 基线 `probs=` 留空、判据表 R13 标"未验"，概率比对路径只用**合成件**证明工具可用。
5. **新增 `-Arm` 判据**：把 A / REF-D / NEG1 / NEG0 的阈值（含 A 项 +214/+404 槽、−3% DMA、decode 噪声带）写死进 extract 脚本，并提供 `-RequireFlagWitness` 迫使施工交出"新旗标启动自证行"（R9；SMEM 零自证的反例已写进表）。

## A4 硬核核对与异常登记

1. **call 数不是读数（推算）**：已对 9 个 R1a 日志全量 grep，**无** marks / call / chunk-call 行；`marks` 只在 `PolyStrata\src\poly\main.cpp:365-378` 内部构造、`n_calls` 在 `engine.cpp:3140-3148` 内部算，均不打印。call 数 = `floor((6792−1)/every)+1`（`conversations.hpp:31` 默认 every=2048）⇒ 4/1/7，标 **推算**。日志里能当读数的只有 `pin chunks direct`、`direct DMAs`、prefill、decode、驻留（墙/体积也是推算：墙=prompt_tokens/prefill，体积=count×1.548288 MB）。
