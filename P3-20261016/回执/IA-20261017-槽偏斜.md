# 回执 · P0-1 槽偏斜量化（task-8）— 2026-10-17

## 1. 任务
`task-8`：零 GPU 只读+只算，量化 5,890 个 GPU 常驻槽在 40 个 MoE 层之间的偏斜、字节口径命中率、与等配额 147 的对照、per-layer 配额的预期增益；负控用 `no-such-profile.txt`；产出详细件 + 回执 + ≤20 行消息。

## 2. 状态
**达成**（5 项必产出全给）。零 GPU、零编译、零进程、未改码；只读输入、只写本回执与详细件（计算用 `python -` 内联，未落临时文件）。
**负控判黄灯**：任务单指定的 `no-such-profile.txt` 与 `p_run.txt` 计数 **Pearson = 0.9971**（≈ p_run/84 的缩放副本）⇒ 只证明"读了另一份文件"，**不能**证明"脚本能分辨不同层间分布"；本席补了镜像置层控（每层分布 L1 差 20.0%）与均匀随机计数控（14.0%）才把这一条证住（§7）。

## 3. 结论（一句话）
**偏斜存在但不严重（Gini 0.0949 / max-min 1.95 / top-5 占 15.59%），且方向是对的**（层内越平越吃槽：槽数↔层命中率相关 −0.814）；**改成 per-layer 等配额 147 是净损失**——字节口径命中率 **68.2985% → 67.9079%（−0.3906 pt = −210,773 次命中 = −652.7 GB）**，而提示路径的**去重 DMA 体积几乎不变**（常驻数没变）；**建议不动或只设 floor=110（代价 −0.0091 pt）**。
