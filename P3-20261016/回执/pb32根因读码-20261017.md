**分块三层（这是 `moe_rows` 的结构）**：
1. **`round_`（专家分轮）**：`per_round = stage_bytes_ / (gu2 + L.d_bytes)`（`:2342`）⇒ **本靶 `sm=48 MiB` ⇒ 48/2.953 ≈ 16 个专家/轮**；`sm=1024` ⇒ 347/轮。
2. **`mq_/mq2_`（一轮里再按 `rg` 行量化）**：`:2377` `Mmq::quantize(xn_, d_tok, mq_, …, rg, …)`；`:2438` `quantize(hx_…, mq2_, …, rows, …)`。
3. **`d_` + `moe_sum`（每 token 一条 `n_used` 长的和）**：`:2470`。

## §3 ★★ 我把 `rows > kSumRows(32)` 与"最后一块不满"逐条查了

- **`round_` 的最后一块**：`while (round_.back() < n_group) push_back(min(back+per_round, n_group))` ⇒ **末尾恰为 `n_group`**（`:2345`）⇒ **最后一轮天然"不满"但边界正确**（`:2413` 用 `group_.begin()+round_[r]` / `+round_[r+1]`）✅。
- **每轮里 `rows == 0` 的专家**：`:2431` `if (rows == 0) continue;` ⇒ **不参与计算** ✅（**"分配了但没写满"在这里被显式跳过**）。
- **`d_` 的行数**：`moe_sum(dx_, d_w, fo_, n_embd_, n_used_, n, st_)`（`:2470`）按 **`n` 行**读 `dx_`；而 **`d_`/`dx_` 的分配**：`d_ = fbuf(kSumRows * out_w)`（`:1569` 是 `d_`），`dx_ = fbuf(rr * n_embd_)`（`:1577`）⇒ **`dx_` 按 `rr = n×22` 行** ✅；**`d_` 按 32 行** ⚠️ —— 但 `d_` 在 `moe_rows` 里只作为 `mmq_->mul(..., dx_, ...)` 的输出？**需核**：`:2439` `mmq_->mul(stage_+down_at, dt, n_embd_, ff, L.d_bytes, m, mq2_, d_rel+…, d_place+r0, rows, most, dx_, n_embd_, st_)` ⇒ **输出是 `dx_`**（按 `rr` 分配）⇒ **`d_` 在 `moe_rows` 里【可能根本不用】**（`d_` 只服务 `moe()` 的 `add_scaled`）⇒ **⇒ `d_` 的 32 行与 pb≥32 无关** ✅（**这条排除了我上一轮对 `d_` 的 NaN 猜测的"moe_rows 侧"**）。

## §4 ★「`sm48` 的 stage 不够」这条线索 —— **我判：不是 NaN 的成因**

- `per_round = 48 MiB / 2.953 MiB ≈ **16 个专家/轮**`（`:2342`）⇒ **只是把一层拆成 ≈32 轮**（512/16），**每一轮都从 `group_` 里取连续的一段**、`rows==0` 的跳过、`bounds` 是全局的 ⇒ **不产生"读到脏数据"**。
- `stage_bytes_` 有下限 `max(…, one_expert)`（`:1668`）⇒ **不会被拆到比一个专家还小** ✅。
- ⇒ ★ **结论：`--stage-mib 48` 应只影响轮数（性能）与 `rel` 索引上界（仍在 1026 内），不解释 NaN**。**⇒ 不需要因为 pb 放大 `--stage-mib`**（这条不改 canonical）；**但仍建议 builder 用 `sm=1024`/`sm=48` 各跑一次 pb=32 作为判别臂**（若两者都 NaN ⇒ 与 stage 无关，坐实）。

## §6 给 builder 的判别臂（零改码，按成本排序）
1. **pb=32 加 `--no-graphs`** ⇒ 判 C1（**最便宜、最可能**）。
2. **pb=32 加 `--stage-mib 1024` 与 `48` 各一次** ⇒ 判"stage 不够"（预期**无差**）。
3. **pb=33 / 48 / 64** ⇒ 若全部 NaN ⇒ 是"≥32 就错"（不随 n 变），更像 C1；若某些档正常 ⇒ 与 `n` 的具体值有关（指向 tile/图）。
4. **pb=32 加 `--no-gpu-experts`（全 CPU）** ⇒ 完全绕开 `moe_rows` ⇒ **若变正确 ⇒ 坐实 NaN 在 `moe_rows` 内**（且与 D 无关）。
