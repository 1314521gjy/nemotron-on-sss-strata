## 结论（一句话）
**2.22× 重复的根因 = conversation-cache 的 checkpoint 每 2048 token 把 prompt 的 `read()` 切成 4 个 call，每个 call 每层都把 ≤341 个专家的 `L.ahead` 整表重搬一遍；用现成 CLI 旗标 `--prompt-cache-every 0` 可在零改码零编译下把 DMA 从 141.0 GB 降到 45.18 GB（−68%）。** `st_` 的 10.1 GB/s 是 sm=48 非 pin 形态的读数，A 臂（pin、1.548 MB/拷贝）只能结构性地判"单飞"，真速率需 D 跑 nsys；借槽对 prefill 是 0 收益（只动 decode）。
