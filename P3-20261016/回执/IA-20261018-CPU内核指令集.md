# 回执 · 情报-N：CPU 专家内核指令集审计 + 提速方案（2026-10-18）

## 1. 任务
lead 专项（零 GPU）：审计 decode CPU 专家点的 int8 指令集（现在用什么 / 本机 i7-13790F 支持什么 / 老师用什么），给 2–3 条可执行改法（改哪/多少行/预期单线程提升/风险/判红），并答"不改算法只改内核 `cpu_us/miss` 能从 100 µs 压到多少"。允许只读反汇编 exe。

## 3. 结论（一句话）
**当前 exe 里一条 VNNI 都没有**（反汇编：`vpdpbusd=0`、`vpdpwssd=0`、`vpmaddubsw=725`）——跑的是 ggml-cpu 的 **AVX2 两段点积（maddubs→madd）+ 每行一次间接 `vec_dot` 调用**；专家类型实测 **up=Q4_K(12)、down=IQ4_NL(20)**，对应 `ggml_vec_dot_q4_K_q8_K`（`quants.c:2038`，无 VNNI 分支）与 `ggml_vec_dot_iq4_nl_q8_0`（`:3920`，无 VNNI 分支）。**本机支持 AVX-VNNI 且工具链已能编**（`STRATA_HAVE_AVXVNNI_INTRINSICS=1`；本 build 的 `iq_avx2.cpp.obj` 有 `vpdpwssd` 763 条），**树里 `strata_kernels_cpu.lib` 已编好 Q4_K/IQ4_NL 行内核（含 IQ4_NL 的 VNNI 运行时版）但 poly 没链、没调**。老师的"高端路径"是 **AVX-512-VNNI（本机无 AVX-512，用不上）**，其 AVX-VNNI 版是 0.1.44.x 才有的——**同源代码已在我们树里**。只改内核预期 **100 → 69–80 µs（保守） / 55–70 µs（含 Q4_K VNNI+unroll）**。

## 5. 三条改法 + 预期
1. **接已有行内核**（~60–100 行：CMake 链库 1 行 + `cpu_experts.cpp:216-249` 换 `kq256_gu_rows`、`:254-274` 换 `iq4nl256_down_rows`）：去掉每专家 3712 次间接调用 + IQ4_NL 半吃 VNNI ⇒ **1.25–1.45× ⇒ 100→69–80 µs**；风险低（位精确 + parity 工具）。
2. **Q4_K 行内核加 AVX-VNNI 变体**（~80–150 行，照 `iq_avx2_rows.inl` 双编译；`dpbusd_avx` 替 maddubs+madd）+ 4 行 unroll + prefetch：**再 −8–15% ⇒ 60–72 µs**；风险中（须保位精确）。
3. **任务粒度 32→64/96 + 全局连续行区间**（~30–60 行；照老师 `pool.cpp:383-419`）：**+5–15% ⇒ 55–68 µs**；风险最低。

**⑤ 能压到多少**：只改内核不改算法 ⇒ **保守 69–80 µs（仅改法 1）；含 2+3 到 55–70 µs**（宿主带宽 32.2 → 40–47 / 46–58 GB/s）。依据：现 11 MFLOP/100 µs = 110 GFLOPS/线程；VNNI 把 dot 的 2 条指令合 1（理论上限 2×），扣解包/scale 后 1.3–1.6× dot 核，再叠 unroll/prefetch 1.1–1.2×。
**前提**：先读那次跑的 `decode: cpu_busy_us/miss`（`main.cpp:792`）——若 100 µs 是 wall（含 launch/交接，`busy=wall−launch_ms`，`engine.cpp:2448-2449`），内核收益要按 busy 段折算。

## 6. 未验 / 边界
- **U1**：100 µs 是 `cpu_us`（wall）还是 `cpu_busy_us`（纯 CPU）；若 wall 含 launch/交接，则"110 GFLOPS/线程"与收益比例要重算。
- **U2**："去掉间接调用省 18–55 µs"是读码+每调用 5–15 ns 的推断（D），未实测。
- **U3**：`kq256_gu_rows` 的 `up_off` 对非门控 Nemotron（无 gate，up 单矩阵）应为 0（`kq_avx2.hpp:12` 定义），未在 GGUF 布局上实测；落地先跑 parity。
- **U4**：`iq4nl256_down_rows` 完整签名被终端截断（`iq_avx2.hpp:44-46`），落地补读。
- **U5**：老师 0.1.40.2 在本机（无 AVX-512）实际 fallback 到哪个 AVX2 函数未逐行追（按全树 dpbusd 只在 expert.cpp 推断为 `s2_expert_*` AVX2 路径）。
