> ★ **已钉死（读 `E:/llama-cpp-pin/ggml/src/ggml-cuda/mmf.cuh:355-379` + 3 例手算）**
> - `expert_bounds` / `ids_dst_compact` 都是 **0 基、按局部紧凑行索引**（`expert_start = expert_bounds[e]`、`ids_dst_expert = ids_dst_compact + expert_start`）。
> - **`rel_local[i] = bounds[b0 + i] − bounds[b0]`**，**首项显式 0**，**末项 = rows_batch = total_rows**。
> - ★ **必须同时做：up 的输入按批切片** `mq_ + (size_t) r0 * xq_row`，其中 **`xq_row = native_q8_1_bytes(in_w)`**（**用 in_w，不是 n_embd_**）。否则局部 0 基 `expert_bounds` 会去读 `mq_` 第 0 行 ⇒ **行错位（有限但错）**。
> - `ids`（up）用 `iota_`（局部恒等）；**down 的 `ids = d_place + r0` 不动**。
> - 批内 down 的行表用 **`rel_local`**（按批首重定基），不用轮级的 `d_rel + …`。

### 3.1 staged 段（`moe_rows` 的 round 循环）也要改（★ 两段都改）
- 每个 round `g0..g0+m` 再按"累计行数 ≤ `scratch_rows_`"切子段；每子段：
  - `up = mul(stage_, gt, ff2, in_w, gu2, m, mq_ + r0*xq_row, d_bounds + g0, iota_, rows_batch, most, gu_, ff2)`
  - `act/quant` 在 `gu_/hx_ + 0`（局部）
  - `down = mul(stage_ + down_at, dt, out_w, ff, d_bytes, m, mq2_, rel_local, d_place + r0, rows_batch, most, dx_, out_w)`
- **cached 段与 staged 段的公式相同**，只是 `slot_of` 与输入缓冲不同。

## 4. `max_count > scratch_rows_` 的兜底（硬要求）
- 在 `count_` 算完后取 `maxc = max_e count_[e]`。
- **若 `maxc > scratch_rows_`** ⇒ 该次调用**整层走旧的全 rr 路径**（`batches_` 为空 + 置回 `scratch_rows_==rr` 的等价行为），**并 `fprintf(stderr, "WARNING: STRATA_SCRATCH_TILE: expert rows %d > tile %zu; this call uses the full-rr path\n")`** —— **响亮、不静默**。
- 注意：`gu_` 的**分配**已按 8192；若 maxc>8192，旧路径需要 rr 大小的 gu_ ⇒ **兜底必须把 T 在分配时抬到 `max(4096, maxc)`**。⇒ **`scratch_rows_` 应在【知道 maxc 之后】定**：`scratch_rows_ = min(rr, max(4096, maxc))`（`tile` 时）；maxc 在 `alloc()` 里可估算（`rows_ * n_used_` 上限，或先按 8192、运行时再警告）。
