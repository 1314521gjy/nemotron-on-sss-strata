一、今晚改动主题（对应实验台账 P3-20261016）
1) 去重：conversation-cache 的 checkpoint 每 2048 token 把 prompt 读切成 4 个 call，
   每层 moe_rows() 对每个 call 重搬 ahead 表 ⇒ 68% DMA 字节是纯重复。
   交付用 --prompt-cache-every 8192 单 call 化（R1 记录为"零改码、仅 flag 生效"）：
   DMA 141.0→44.58 GB，prefill 652.6→1354.4 tok/s。
2) ring 双缓冲：STRATA_STAGE_RING2 第二 staging 槽 + event 配对（st_/up_ 四处纪律），
   prefill 1731.7→1906.7 tok/s；气泡 39 次/0.350 s→1 次/0.005 s 另由 route 单遍贡献。
3) route 单遍：nemotronhmoe.cpp route() 改为 32 槽单遍插入（top-22），逐位等价，消掉
   每层 8–10 ms 的 host CPU 路由气泡。
4) mamba2scan warp/树形实验：kernels.cu 内失败路线以 #if 0 封存（含失败记录注释），
   旧 SMEM/global 两分支一字未动；源码状态以回退版交付。
5) 线程放置：新增 header-only src/poly/threads.hpp（logical/physical CPU、pin、Plan）；
   --host-core first|last|<n> / --aux-cpus auto|off|<list>；默认全 off（不调用 OS 亲和 API，
   实测默认 pinning 会掉 decode 约 11%，故默认=现状）。
6) 旋钮化：kSwapMin/kSwapHalf/kSwapRatio 默认值移入 Options 单一出处（engine.hpp），
   新增 --adapt-min-gain / --swap-half / --swap-ratio，默认值下与旧式逐位同。
7) pcie 骨架：--pcie-frac / --pcie-slots / --pcie-auto 只做 staging 槽 arena 预留 + 打点行，
   无分流/DMA/copy 逻辑；frac=0（默认）不分配、不打自证行。
8) 分段计数器：fill / prefill staging / swap 三段各自次数与 bytes 记账（main.cpp copy ledger），
   V0 全默认与基线 ids/概率逐位同。
