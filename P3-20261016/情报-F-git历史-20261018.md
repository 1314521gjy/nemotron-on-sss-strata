### §4.3 "特别参数"深挖（含原文数字；**每条标机器**——不许当我们的读数）

① **`STRATA_ROUTE_TAIL_SKIP=7`（0.1.42 默认）**：decode **1.129×（A4000）/ 1.146×（P100）/ 1.156×（3060）**，5/5 对更快；`=0` 逐字节恢复旧答案；KL 0.0032–0.0058；**只影响 decode，不影响 prompt**；命中率≥90% 时自动关（可 `TAIL_SKIP_MAX_CACHED` 调）。
   ★ **换算到我们 top-22**：老师是 **top-10 砍 rank 7–9（30%）**；我们 top-22 同比例 ⇒ **`--tail-skip 15`（砍 rank 15–21，7/22 = 31.8%）**。**队里以前试的是 `6`（砍 16/22 = 73%）——那是另一个量级，被判"近似档禁开"情有可原，但结论对"15"不成立。**

③ **`STRATA_PCIE_BALANCE=1`（0.1.44.1）**：每层按拟合选 m（CPU 42–60 µs/专家 vs GPU 28 µs/PCIe 专家）；**16.77/17.17 → 12.98/12.82 ms/round**（5090 单 AVX2 worker；16 worker 时 pool DRAM-bound ⇒ 12.19→12.17 不动）。
④ **`STRATA_EXCHANGE_ROTATE=1`（0.1.43.x → 0.1.44.1 扩到非均匀 pack）**：**161.6–165.1 → 184.9–188.7 tok/s**（5090 IQ3_S 128K，5/4 跑）；serve 23 turns 147.8/159.2/158.4 → **175.2/184.9/172.8**；代价：exchange 分配涨到 1.06 GiB 页锁（`--adapt-swaps 80`）。

⑥ **`STRATA_ADAPT_CALLBACK_WARMUP`（0.1.43.1 默认 Linux）**：**142.82 → 207.75 tok/s（+45%）**（5090/9950X，4K 三 prompt 平均）；"其他 GPU/驱动未测" ⇒ C 级、机器特化。

## §5 结论：最可能的 1–3 个"我们没发现的杠杆"

1. **`--tail-skip 15`（上游 `STRATA_ROUTE_TAIL_SKIP=7` 的 top-22 等价值）**——**名字**：我们**已有**该旗标/env（`main.cpp:800/855/922`、`engine.cpp:2118-2133`），**跑法写死 `--tail-skip 0`**；**宣称收益**：老师 decode **1.13–1.16×**（单卡 5/5 对，KL 0.003–0.006，`DETAILS.md:1651-1659`）；**我们缺它的后果**：decode 时漏专家照搬照算（我们 D 跑 `1994 experts swapped into VRAM`，decode 12.30 tok/s），而**"正确换算值"从未被我们测过**（以前测的 6 = 73% 砍掉，量级不对）；**抄它要不要编译**：**不用**（`--tail-skip 15` 或 `STRATA_ROUTE_TAIL_SKIP=15`，加一条 id 逐位/`--top-probs` 判据即可）。
2. **decode 侧 `--pcie-frac` + 自动 share（`STRATA_PCIE_FRAC_DEFAULT` / `STRATA_PCIE_BALANCE`）**——**名字**：`--pcie-frac`、`STRATA_PCIE_FRAC_DEFAULT`、`STRATA_PCIE_BALANCE`；**宣称收益**：3060 **1.300×**（share 0.55→0.20）、PCIE_BALANCE **−23% ms/round**（5090 单 worker）；**我们缺它的后果**：`grep pcie src/poly` **0 命中** ⇒ 我们的 decode **没有"把一部分漏专家搬到 GPU 算"的通路**，所有漏专家只能压 CPU 池（GPU 等 CPU 的行）；**抄它要不要编译**：**要**（新机制：PCIe 拷贝通路 + 按实测成本定 share，约 1 个 knob + 1 个拟合器）。
3. **`--host-core last` + `--aux-cpus auto`（Windows 线程放置）**——**名字**：`--host-core`、`--aux-cpus`（0.1.43.1 新）；**宣称收益**：`--aux-cpus auto` 在 2×3080 上 **+11%**（off/auto 0.89–0.91），`--host-core last` 是"Windows GPU 中断落在第一个逻辑核，host 自旋在那就等中断"的对症开关；**我们缺它的后果**：poly **没有任何线程放置旗标**（只有 `--threads 24`），而我们是 **Windows 单卡 + 24 线程自旋**，正好在这个坑的形态里；**抄它要不要编译**：**小改**（`SetThreadAffinityMask`/`pin_current_thread` 一行 + 一个 flag；**只挪线程、不改结果**，零精度风险）。
> 备选（收益更大但机器特化/更贵）：`STRATA_EXCHANGE_ROTATE`（+14%，需交换缓冲基建）、`STRATA_ADAPT_CALLBACK_WARMUP`（+45%，只在 Linux 5090 测过）、`STRATA_ADAPT_OVERLAP`（Windows 上实测可能负）。
