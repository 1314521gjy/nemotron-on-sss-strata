## 2. 是「连续传播」还是「layer1 突变」？（A，算式）

**engine embd ≈ ref embd**：`attn_norm-0` 只差 0.019% ⇒ embd 差 ~3e-6，可忽略。
⇒ **`block_out-0` 的差 ≈ `mamba_out-0` 的差** = `(3.0e-4, -2.31e-4, 5e-5)`（ch0/1/2）。

`attn_norm-1` 是 `RMS_NORM(block)` 再乘权重：`attn_norm_j = w_j · block_j / rms`。故
```
Δattn_norm_j  =  (w_j / rms) · Δblock_j           ← 线性增益
```
从参考值反解 `1/rms = norm-1_j / block_j`：ch0 **50.3**、ch1 **49.0**、ch2 **49.1** ⇒ `rms ≈ 0.0204`。
再反解 `w_j = attn_norm_j / norm-1_j`：ch0 0.0038、ch1 0.2656、ch2 0.4473。
⇒ **理论增益 `w_j·(1/rms)`**：ch0 **0.19**、ch1 **13.0**、ch2 **21.9**。
⇒ **实测增益 `Δattn_norm_j / Δblock_j`**：ch0 **0.23**、ch1 **12.81**、ch2 **16.02**。

**两者逐通道吻合**（ch2 的小偏差来自印刷 4dp）⇒ **layer1 输入的 3.9% 可被 layer0 残差的 2.31e-4、经 RMSNorm 的 ~13× 增益（`1/rms≈49`、`w₁≈0.27`）完整解释**。
更直接：`Δch1 = 2.31e-4 × 12.8 = 2.96e-3` = **实测 2.96e-3**，逐位对上。

### ⇒ 结论（回答队长的判据）
- **不是「layer1 突变」，是「layer0 → layer1 连续放大」**。layer1 的**输入侧没有发现新的逻辑错**。
- 队长的分支「**若 layer0 输出已经差、且连续 ⇒ 数值地板，新 PASS 定义成立**」——**连续性成立、被证实**（增益由 RMSNorm 定量复现）。

## 3. ★ 但必须同时记：**layer0 的 `mamba_out-0` 差是真的，不是印刷噪声**
