## §3 语义判读（人工 + 客观代理）

- 文本内容：通顺英文 essay，直接续 prompt 结尾（`…it will happily` → `delete the check you wrote…`），主题=编译器/未定义行为/抽象塔，**无事实错误、无乱码、无同义反复**。
- ★ **必须写明的口径**：该 prompt 本身是**重复模板**（53 段；`delete the check you wrote` 出现 **8** 次、`The history of computing is a history` 出现 **10** 次）⇒ **生成文本是 prompt 的逐字子串**（256-token 文本整体落在 `prompt[6421…]`，128-token 亦然）⇒ 本测试只能证明"**没变傻到乱码/循环崩溃**"，**不能证明"语言能力强"**；同理，任何"输出与 prompt 逐字同"的假绿都要扣掉这层。
- 客观指标（128 token，全臂相同；T15-256 括号内）：token `D1=0.633 / D2=0.937 / Period=0 / max_identical_run=1 / max_repeat_3gram=2`（256：D1=0.582、D2=0.910、Period=0）；词级 distinct2=0.945（256：0.945）、distinct3=1.000（0.995）；词 4/5/6-gram 最大重复均为 **1**；256-token 前半 vs 后半相似度 0.201（无整体复读）。

- **"概率小但文本坏了"的报法（写死）**：若出现"ids/文本有分歧、但 max|Δp| ≤1e-3"⇒ **文本判据不足，报 lead**（说明漂移不在概率上能看见）；若"ids/文本全同、但 max|Δp|≥0.10"⇒ **near-flip 风险**，必须补多 prompt/更长生成，不得判绿。

## §7 最容易被假绿骗过的一条

**"ids/文本与无损基线逐位相同 ⇒ 判'无损'"**。本次产物就长这样：但它同时满足两个弱条件——① prompt 是**重复模板**（生成=逐字复述 prompt 片段）；② 只有 **128 token、单 prompt**。在这种输入上"跳 32% 专家仍不改 argmax"是**该 prompt 的性质**，不能外推到真实任务；T11p 的 13.4 pt near-flip 已经说明概率层在动。⇒ 交付质量结论必须叠加：**概率对齐（L4）+ 多 prompt（L6）+ 长生成（L5）**，否则逐位同 = 假绿。
