## §1 独立算法（不是抄施工表）

1. **decode**：从每份日志最后一条 `prompt N tokens … generated 128 tokens X tok/s` 行提取 X；我自己排序取中位、自己算相对差。
2. **tokens/round / accepted**：从 ledger 行提取 `rounds=`、`tokens/round=`、`hist=`；从 summary 提取 `N of M guessed tokens right`；另用 `produced/(produced−accepted)` 独立交叉算（128/(128−112)=8.00）。
3. **ids**：从每份日志取最后一条纯逗号 id 行，按 token 列表**逐位比较**（不是文件存在性、不是自述）。
4. **peak**：读 `R60-del-*-peak.txt` **全文件每一行**（`N MiB`），取最大值；算 R21 余量 `32,760 − max`。
5. **prefill/refill**：从 summary 的 `prompt N tokens Y tok/s` 取 Y；从 `borrow: lent … refill X ms` 行取 refill。
6. **ReLU²**：R57 日志的 ids 行 + `R57-*-ids.txt` 逐 token memcmp；parity 查 `stageC-parity.*`/日志原文；A/B 查 `run_R57D_all.ps1` / `run_R57E_all.ps1` 的 arm 定义与各臂日志。**没有读 R55/R57/R60 的 summary json。**
