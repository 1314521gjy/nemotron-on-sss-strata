## §2 为什么这算"异构"（不是又一条模板）

1. **语言/脚本不同**：2 条英文 + 1 条中文；不同 tokenizer 区段（中文字节级 BPE vs 英文词级）。
2. **能力不同**：算术推理（qa）· 代码语义审计（code）· 中文指令跟随/摘要/CAP 取舍（zh）——互相不重叠。
3. **答案形态不同**：数字+判断（qa）· 散文+代码+单元测试（code）· 三条结构化中文（zh）——防止"输出形态本身"造成假差异。
4. **互不重叠**（本席实算）：4 条之间的 token-5gram Jaccard **最大 0.0059**（code↔alt），其余全 0.0000。
5. **结构唯一**（本席实算）：4 条 prompt 的**段落 distinct 比例 = 100%**、**句子 distinct 比例 = 100%**；对照 p6792：53 段只有 **9** 段不同（0.17）、259 句只有 **29** 句不同（0.11）⇒ p6792 是"同 6 块模板循环 5–9 遍"的复制型 prompt。

## §4 Tokenize 规程（可复现，零 GPU）

```powershell
# 1) prompt 原文放 ASCII 路径（llama.cpp 不支持中文路径）
#    C:\sp3\bench\{qa,code,zh}.txt（原文已在）
# 2) 转 ids（与 lead 指定口径一致：--ids --no-bos）
E:\llama-cpp-upstream\llama-tokenize.exe `
  -m E:\models\Nemotron-3.5-Super-VL-120B-A12B-Q4_K_M\NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-Q4_K_M-00001-of-00002.gguf `
  -f C:\sp3\bench\qa.txt --ids --no-bos
# 3) ids 落盘：C:\sp3\bench\qa_ids.txt（一行逗号）
```

- **往返验证（每条都必须做，30 秒）**：
  ```powershell
  python "...\验收\decode_ids_gpt2.py" C:\sp3\bench\zh_ids.txt C:\sp3\bench\zh_decoded.txt
  llama-tokenize.exe -m <GGUF> -f C:\sp3\bench\zh_decoded.txt --ids --no-bos
  # 输出必须与 zh_ids.txt 逐位相同
  ```
- **本席实测往返**：qa **218/218** · code **240/240** · zh **281/281** · alt **293/293** 全等 ⇒ 4 条 ids 可放心喂 `--tokens-file`。
- ★ **坑（必须写进交接）**：现成 `detok.py` 的"token 字符串直接拼接"**只对 ASCII 正确**；本 GGUF 是 `tokenizer.ggml.model = gpt2`（byte-level BPE，`pre=pixtral`）⇒ **中文必须用新工具 `decode_ids_gpt2.py`**（GPT-2 byte→unicode 逆映射）。实测：zh 用 detok.py 解出的文本再 tokenize = **1280 ids**（错）；用 decode_ids_gpt2.py = **281/281**（对）。先前英文 prompt 不受影响（ASCII 下两法等价，已验证 p6792 文本与旧 ref 文件逐字同）。
- 附带发现：`detok.py` 在 GBK 控制台遇中文会抛 `UnicodeEncodeError`；脚本输出请设 `PYTHONIOENCODING=utf-8` 或写文件。

## §5 台子怎么用（给施工席的跑法规格；本席不跑）

| 项 | 规格 |
|---|---|
| 载入 | `--tokens-file C:\sp3\bench\<cls>_ids.txt`（与 p6792 同机制） |
| 生成长度 | **128 token**（速度/ids 可比 R18）；长生成另跑 **256**（只对 T15 等候选档） |
| 每配置 | **3 个非-probs 跑**（速度中位）+ **1 个 `--top-probs 8` 跑**（D5 概率）+ **1 个 `--expert-swaps 0` 跑**（D4 确定性） |
| 每跑 | 冻结 profile（`copy p_master→p_run`）、报峰值 VRAM、exe sha、命令行；一次一跑 |
| 报数 | **逐 prompt 报**（qa/code/zh/alt 各一列），不许只报平均；p6792 只作历史对照、**禁止对外报** |
| 优先顺序 | qa → code → zh（alt 作为第 4 条快检）；若时间只够 2 条：qa + zh（语言/题型差异最大） |

## §6 这台子能证明 / 不能证明什么

**能**：① 某 decode 优化是否**只在 p6792 模板上有效**（跨 4 条 prompt 不复现 ⇒ 判红）；② 输出质量是否在异构输入上退化（ids/文本/概率/反抄门）；③ 不同语言/任务下速度差异。
**不能**：① 不能证"语言能力强"（4 条题仍小样本，答案对错需人工/独立模型判）；② 不能替代独立参考实现（"引擎没把模型弄傻"仍须 `task-17` 的 llama.cpp 对照）；③ 不能证统计显著（3 跑中位只给量级，不排除环境漂移）；④ 单条 prompt 的任何结论都不能外推。
