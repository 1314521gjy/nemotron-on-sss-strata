## 6. ★★ 钉口径后的正式对照（2026-10-16 补，队长裁"先钉口径再谈谁快"）

**口径（钉死）= 同 prompt 文件 `perf_prompt_long.txt`（≈700 token）· 单次补全 · 无投机 · `-c 4096 -fa on -t 16`**
- **llama 侧**：本版**无 `-no-cnv`**（实测 `error: invalid argument`）⇒ 改用 **`llama-completion.exe`**（= 单次补全二进制，包内自带）。
- **我方**：**同 ids（同 prompt 文件）· `--max-new 45` · `--no-draft --lookup 0` · 冻结 profile（母本协议）· 整批预热 1 跑丢弃 · 3 跑取中位**。

| 量 | **llama.cpp（llama-completion, N=24）** | **我方引擎（`978d64bc…`）** | 谁快 |
|---|---|---|---|
| **prefill t/s** | 26.45 / 21.37 → **中位 23.9**（差 **19%**） | **36.3 / 37.2 / 35.4 → 中位 36.3**（紧密） | **我方 ~1.5×** |
| **decode t/s** | 6.61 / 6.68 → **中位 6.65** | **24.88 / 25.78 / 24.03 → 中位 24.88** | **我方 ~3.7×** |
| 生成 | 44 run（`n_predict 45`） | **45 (stop) ×3** | 同口径 ✓ |
| **装载时间** | **41.9 s / 37.4 s** | **9.4 / 9.7 / 9.5 s**（取自 log 行 `strata-poly: loaded in X s`，**非另计时**） | 我方快 ~4× |
| **显存峰值** | **32156 / 32146 MiB**（32759 上限 ⇒ 近满） | **29837 MiB** | 我方低 ~2.3 GB |

**★ 结论（同口径下）**：**我方引擎 prefill 快 ~1.5×、decode 快 ~3.7×**。
**★ 两个口径分列（不许混比）**：
- **真实 prompt（本表）⇒ 我方快** ← **唯一可进结论的一对**；
- **合成口径 `llama-bench pp700`（43.95）⇒ 只能当"llama 上界/合成参考"**，**不许与真实口径混着比**。

**★ 顺带定死"反常"**：llama 在 **N=24 显存已近满**（32156/32759 MiB）⇒ **再压小 N = 超配** ⇒ 合 `engine.cpp:988-993` 那条注释（"Windows 上被要超过实有的卡不拒绝：搬到系统内存，30 变 13"）⇒ **tok/s 掉** ✓（**用显存读数定死，非 tok/s 反推**）。

**负控/未验**：llama 两次 prefill 差 **19%**（临界 20%）⇒ **该口径的 prefill 也带 ~±10% 噪声**；我方**装载时间未测**；**两口径的 KV/ctx 实现不同**（慎比 decode 绝对值）。

### §6.1 我方 §6 的完整旗标（可复现）

```
# 每次跑前：cp <母本 p_master.txt> <p_run.txt>   （冻结 profile）
strata-poly.exe --model <…-00001-of-00002.gguf> --tokens <long_ids.txt, 700> \
  --max-new 45 --prompt-batch 8 --cpu-share 0.55 --expert-swaps 64 --tail-skip 0 \

```

### §6.2 ★ 口径差（别混引）

**我方 §6 的 prefill 36.3 明显高于早批 `g0q/g0r` 的 19.8–25.8** —— 二者**口径不同**：早批是 **`--max-new 64` + 未喂 profile + 未预热**；§6 是 **`--max-new 45` + 冻结 profile + 预热**。**⇒ 两个数不许混引。主因（如"冻结 profile 提高命中/预热拉稳时钟"）**未验，待查**。**

### §6.3 ★ 反组"反常"定死

llama `--n-cpu-moe` **N=24 时显存已近满**（**32156 / 32146 MiB**，上限 32759）⇒ **再压小 N = 超配** ⇒ 合引擎自身注释 `engine.cpp:988-993`（"Windows 上被要超过实有的卡不会拒绝：内存搬到系统的，**30 tok/s 的活干成 13**"）⇒ **下游 N 的 tok/s 掉**（N=18 只剩 3.90）。**用显存读数定死，非 tok/s 反推。**
