## 4. 新判据 / 新纪律（今天踩出来的，必须继承）

1. **类 E「计算路径变化」档**（`--pcie-frac>0`、任何 CPU↔GPU 换算法位置）：不要求逐位，但须 ①**ids 逐位（≥2 条不同 prompt）** ②**文本逐字同** ③**确定性**（同配置重复跑概率逐位同） ④`max|Δp|` 记录且**无 >0.05 跳**，near-flip(margin<0.05) 单列 ⑤默认值仍关。
2. **确定性对照必须 `--expert-swaps 0`**：交付配置在冷缓存 prompt 上**同配置重复跑都不逐位**（换入 2,700+ 专家、A0 vs A0b 也翻 1 个 id）。要逐位判就先关 swaps。
3. **probs 对比一律静默窗口**：挂 VRAM 采样器的跑会从 pos97/65 起漂（max|Δp| 0.11，ids 不变）⇒ 采样器扰动时序。
4. **`--draft-dump` 只作语义检查**：它的 stderr 打印会经时序影响计时型 `guesses` 决策（D1 vs D2 仅差 dump 也 ids 不同）。
5. **tokens/round / 兑现率有盘上来源**：`main.cpp:660-668` 的 `DONE` 行 = `generated/prompt/prompt_ms/decode_ms/finish/drafts_accepted/drafts_offered/reused` ⇒ `tokens/round=generated/reused`、兑现率=`accepted/offered`。
6. **基准代表性**：p6792 是重复模板（"delete the check"×8 / "The history"×10 / 53 段），续写=抄 prompt 子串 ⇒ **只能证"无乱码/无退化"，不能证语言能力、且严重高估 lookup/MTP**。异构 prompt 用 `C:\sp3\alt_prompt.txt`（293 tok，C++ 题+哈希表问答），ids `C:\sp3\alt_prompt_ids.txt`。

### 9.4 decode 收口结论（下一棒直接继承）
```
decode 每 token ≈ miss/token × cpu_us/miss + ~18 ms 固定
              = 496.7 × 96 µs + 18 ms ≈ 65 ms  （threads 16，alt prompt）
```
- **miss/token**：只随 prompt 变；降它 = 更多驻留（VRAM 已满）或**有损**（已裁决排除）

### 9.5 口径纠偏（`reviewer` 独立复核，**以本节为准**）
1. **跑法剧本计数**：实测 **239 个（含 `--tokens-file`）/ 224 个 `--no-draft` / 168 个 `--lookup 0`** —— 情报口径 235/228/170 作废。
2. **p6792 的 +57%/+77% 只能乘法拆**：`倍速 = tokens/round ÷ 每轮成本比`。
   - 128 口径：8.000 ÷ 5.044 = 1.586（实测 1.574）· 256 口径：8.000 ÷ 4.453 = 1.796（实测 1.789）——误差 <1%
   - ★ **"lookup 命中跳过计算"假设被否定**：被接受 token 仍在批量验证中被计算，省的是"8 token 的轮只花 5.05/4.45 单 token 成本"的**批处理摊薄**
   - **lookup 相对 draft 只 +4.1%**（22.19 vs 21.31）；8 token/轮来自 **p6792 重复模板的 100% 接受率**
3. **`tokens/round` 是推算值**：盘上 6 份日志里 **`DONE` 行 0 条、窗口自证行 0 条** ⇒ 以后必须由引擎打印自证，不能再用推算数当判据。
4. **`交接件` §8.3 里"D2 203 ms/轮"与日志可复算 177.5 ms/轮差 12.6%** ⇒ 引用前先按日志重算（本件保留旧数并在此标更正）。
5. **判据补丁（以后所有 decode 实验必须带）**：
   a) **同批 CTRL 首尾配对**，差 >5% 整块作废 + 预热跑/首轮剔除
   b) **三列同报**：`tokens/round`（标"推算/自证"）+ `accepted/offered` + per-round ms（拆 CPU 腿=`miss/token×cpu_us/miss` 与非 CPU）
   c) **≥2 条异构 prompt**（qa/code/zh/alt），p6792 只作历史
   d) **质量+自证捆绑**：新 exe sha · 窗口自证行 · ids 逐位（≥2 prompt）· 全位置 Δp+near-flip · copy-ledger 两列 fill · R21 峰值 —— **全绿才采纳**
6. **对"窗口栈是最大杠杆"的最终裁决（独立复核 + R40 实测一致）**：**只在 p6792 模板上成立**；异构 alt 上 −2.8%（lookup）/ +2.2%（draft，且驻留不同非纯对照）⇒ **不能称最大杠杆**。
