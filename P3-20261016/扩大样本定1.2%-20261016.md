## ③ 结论（第一步）

1. **「1.2%」不是一个稳定的相对数字。** 逐 token 的**绝对残差**（routed 链）在 **0.3×–9.4× 半步** 之间跳：
   - **pos0 / pos2 / pos3 / pos4：≤ ~1.5× 半步** ⇒ **落在印刷地板内**（与"对齐到噪声级"一致）；
   - **pos1：7–9× 半步（~4e-4 绝对）** ⇒ **高于印刷地板** ⇒ **那一个 token 上确实还有真实残差**。
2. ⇒ **第一步【不能】把它定死**（既非稳定 1.2%，也非全为噪声）。**⇒ 触发第二步**（见 §⑤）。
3. **输入侧（`moe_in`）在 5 个 token 上全部差 100–344× 半步** ⇒ 是**真差**，但它是**继承**来的（layer-1 输入，含 layer0 的 t14 小差经 latent_down），**不是 routed 计算本身**。
4. ⇒ 与队长「稳定 ⇒ 真差；±1 半步内抖动 ⇒ 印刷地板」的两分支：**实际是第三种 —— 「多数在抖动带内、个别 token 越线」**，故**必须上更高精度参考**才能定死。
